# pamyat

Память студии из команды агентов, которая делает сайты с нуля и дорабатывает готовые:
от разговора с заказчиком и ТЗ до дизайна, текстов, сборки и проверки качества.

## Структура

| Папка | Что внутри | Едет в сервис |
|---|---|---|
| `prod/` | Студия для заказчиков: менеджер, 21 агент в 7 отделах, память каждой роли | **да** |
| `lab/` | Обучение: зеркало команды с черновиками, общение с владельцем, тестовые заказчики | нет |
| `team/` | Команда людей: как подключиться, правила, участники | нет |
| `service/` | Архитектура сервиса и подключения | нет |
| `projects/` | Проекты, сделанные в лаборатории | нет |
| `.claude/` | Агенты (ссылка на прод) и процедуры лаборатории: разбор, перенос в прод, тест прода | нет |

- **Как всё устроено — `ARCHITECTURE.md`. Железные правила — `RULES.md`.**
- Начать работу — `START.md`.
- Сотрудникам — `team/README.md`.
- Правила для агента в лаборатории — `CLAUDE.md`, для прод-студии — `prod/CLAUDE.md`.

## Команда студии
```
Заказчик ⇄ Менеджер проекта (единственный, кто говорит с заказчиком)
             │  продюсер — план работ
             ├─ Клиентский отдел: аналитик ★, маркетолог
             ├─ Разбор: аудитор
             ├─ Дизайн: арт-директор ★, UX, UI, бренд, моушн, фоторедактор
             ├─ Контент: шеф-редактор ★, копирайтер, SEO, переводчик
             ├─ Разработка: техлид ★, фронтенд, перенос, (QA по ходу сборки)
             └─ Качество: руководитель ★, QA, скорость и доступность, юрист
★ — руководитель отдела: раздаёт работу своим специалистам и принимает её
```

## Этапы
0 Знакомство → 1 Бриф / разбор готового сайта → план → 2 ТЗ → 3 Дизайн ∥ 4 Тексты →
5 Сборка → 6 Качество → 7 Правки → 8 Сдача
