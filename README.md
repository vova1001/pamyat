# pamyat

Память агента-студии, который делает сайты под ключ: от идеи и макета в Figma
до регистрации заказчика в сервисах и запуска на домене.

## Структура

| Папка | Что внутри | Едет в сервис |
|---|---|---|
| `prod/` | Агент для заказчиков: этапы работы и общение с клиентом | **да** |
| `lab/` | Обучение: черновики правил, отклонённое, журнал, тестовые заказчики | нет |
| `team/` | Совместная работа: как подключиться, правила, участники | нет |
| `service/` | Архитектура сервиса и подключения (Figma, Vercel, домены…) | нет |
| `projects/` | Проекты, сделанные в лаборатории | нет |
| `.claude/skills/` | Процедуры лаборатории: разбор, перенос в прод, тест прода | нет |

- Начать работу — `START.md`.
- Сотрудникам — `team/README.md`.
- Правила для агента в лаборатории — `CLAUDE.md`, для прод-агента — `prod/CLAUDE.md`.

## Этапы работы прод-агента
0 Знакомство → 1 Бриф / разбор готового сайта → 2 Структура → 3 Стиль и макет в Figma →
4 Тексты → 5 Сборка → 6 Правки → 7 Регистрация в сервисах и оплата → 8 Запуск → 9 Сопровождение
