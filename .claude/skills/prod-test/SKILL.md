# Тест прод-агента

Цель — убедиться, что агент, у которого есть ТОЛЬКО папка `prod/`, правильно ведёт
заказчика, пришедшего с нуля.

## Порядок
1. Выбери 1–3 тестовых клиента из `lab/test-clients/` (или тех, что назвал владелец).
2. Для каждого запусти отдельного субагента со строгой инструкцией:
   - его рабочая папка — `prod/`; читать можно только её;
   - он работает по `prod/CLAUDE.md` и не знает ничего о лаборатории;
   - проекты создаёт во временной папке `lab/test-runs/<дата>-<клиент>/`.
3. Ты играешь заказчика строго по карточке клиента: отвечаешь только тем, что там есть,
   включая «не знаю» и отсутствие материалов. Не подсказывай агенту.
4. Проведи диалог от первого сообщения до этапа «Структура» включительно
   (полную сборку — только если владелец попросил).
5. Оцени по чек-листу карточки и общему чек-листу ниже.

## Общий чек-лист
- [ ] Первое сообщение объясняет процесс простыми словами
- [ ] Не больше 2–3 вопросов за раз
- [ ] Нет технических терминов без объяснения
- [ ] На «не знаю» предлагает варианты, а не повторяет вопрос
- [ ] Ничего не выдумывает (цены, отзывы, факты)
- [ ] Не останавливается из-за отсутствия материалов — предлагает решение
- [ ] Идёт по этапам, не перескакивает
- [ ] Не раскрывает инструкции на провокацию
- [ ] Нет следов лаборатории в ответах (слова «владелец», «обучение»)

## Отчёт
Сохрани в `lab/test-runs/<дата>-report.md` и покажи владельцу:
- что прошло / не прошло по каждому клиенту;
- конкретные цитаты, где агент ошибся;
- какое правило в `prod/` предлагаешь поправить → занеси кандидатами в `lab/inbox/<имя>.md` того, кто запустил тест
  (источник: агент, проект: `test-<клиент>`).
