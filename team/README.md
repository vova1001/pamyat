# Команда

Как сотрудники подключаются к репозиторию и вместе обучают агента.

| Файл | О чём |
|---|---|
| `rules.md` | Правила совместной работы: ветки, pull request, кто что одобряет |
| `members.md` | Кто обучает агента и где его черновики |

## Как подключиться (для сотрудника)
1. Владелец добавляет вас в репозиторий: GitHub → Settings → Collaborators.
2. У вас свой аккаунт Claude с подключённым GitHub (claude.ai → Настройки → Коннекторы).
3. Откройте репозиторий в Claude Code. Агент сам прочитает правила лаборатории.
4. В первом сообщении назовитесь: «Я <имя>, сотрудник». Агент будет писать ваши
   наблюдения в `lab/inbox/<имя>.md`.
5. Работайте в своей ветке. Готовое — через pull request, его одобряет владелец.

Команды для работы с агентом — в `START.md`.
