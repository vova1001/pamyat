# 13 · tech-lead · вход через Telegram + почта для всех без домена

## Задача
- **Цель:** пока нет домена, код по почте (Resend) доходит только до одного адреса. Заказчик: «сделаем 2 варианта —
  через Telegram или через почту». Ветка `tg-login` `/home/user/ai-studio` (от `studio-sdk`).
- **Что сдать:**
  1. **Вход через Telegram** (deep-link, без виджета и без домена): на `/login` кнопка «Войти через Telegram» → сайт
     создаёт одноразовый токен входа (короткий срок, хеш в БД) → открывает `https://t.me/<bot>?start=login_<token>` →
     бот (уже есть вебхук `/api/telegram/webhook`, секрет `TELEGRAM_WEBHOOK_SECRET`) получает /start, привязывает
     telegram id и отвечает кнопкой «Подтвердить вход» (или сразу подтверждает) → страница входа опросом/SSE видит
     подтверждение и логинит. Согласие (оферта + ПДн) — те же две галочки до нажатия. Новый пользователь создаётся по
     telegram id (имя и @username из Telegram, почта пустая — потом можно добавить в профиле). Существующий — по
     привязке. В профиле: «Telegram привязан / привязать», «почта привязана / добавить». Админка: Telegram в карточке
     пользователя. Установка вебхука бота: команда `api telegram-setup` или авто при старте, если задан токен
     (`setWebhook` на `${APP_URL}/api/telegram/webhook` с secret_token). `TELEGRAM_BOT_USERNAME` — брать через `getMe`,
     если не задан. Защита: токен одноразовый, привязан к браузерной сессии (cookie), срок 5–10 минут, лимит попыток.
  2. **Почта без домена:** провайдер **Brevo** (HTTP API, `BREVO_API_KEY`, отправитель `MAIL_FROM`, например
     studio_worker@mail.ru — подтверждается в Brevo). Порядок выбора: Brevo → Resend → SMTP → лог. Документировать в README.
  3. Если почтовый провайдер вернул ошибку «нельзя этому адресату» — на странице входа понятное сообщение и
     предложение «Войти через Telegram», а не немое «Отправили код».
- **Окружение:** как в задачах 09–12. Бота в тесте нет — имитация Telegram API (тест-сервер) + юнит-тесты;
  живую проверку сделает менеджер, когда заказчик вставит токен в Render.
- **Границы:** стиль Lumen, только свои элементы; секреты не в код.
- **Когда готово — СТРОГО:** в браузере на имитации: вход через Telegram новым и существующим пользователем, отказ по
  просроченному токену, привязка в профиле; вход по почте как раньше; go test, lint, typecheck, build. Коммиты в
  `tg-login`, push.
