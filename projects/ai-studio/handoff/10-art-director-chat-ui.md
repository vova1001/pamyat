# 10 · art-director · интерфейс чата: кнопки, карточки, формы в переписке

## Задача
- **Цель:** заказчик: «внутренний интерфейс, чтобы в чате красиво всё было, кнопки, чтобы выбирать ответы, всё продумать».
  Чат кабинета (`web/src/app/cabinet/chat.tsx`, `components/message-bubble.tsx`) и чат администратора в админке
  (`app/admin/(panel)/users/[id]/admin-chat.tsx`, раздел «Сессии» — новый).
- **Входные файлы:** `../design/design-spec-v3.md` (стиль Lumen, искра), код ветки `agent-bridge` `/home/user/ai-studio`,
  скриншоты: scratchpad `final/cab-chat-d.png`, `final/m-dark_cabinet_chat.png`.
- **Что сдать:** `../design/design-spec-chat.md` — типы сообщений и их вид (свет/тьма, 375/1440), конкретный JSX/классы:
  текст (markdown: списки, ссылки, жирный), **быстрые ответы-кнопки** (одиночный и множественный выбор, «свой вариант»),
  **карточки выбора** (картинка/иконка, заголовок, подпись, «рекомендуем»), **форма в чате** (поля: текст, почта,
  телефон, код из СМС, выбор; отправка; после отправки — свёрнутый итог), **оплата** (сумма, за что, кнопка, статус),
  **превью/версия** (скриншот, ссылка, «согласовать» / «нужны правки»), **файлы** (картинки галереей, документы),
  **этап/прогресс**, **системные** (подписка, этап сменился), «печатает…», «агент думает», «на связи человек»
  (кто отвечает: агент / администратор), ошибка отправки с повтором, пустой чат с подсказками-стартерами,
  поле ввода (вложения перетаскиванием, Enter/Shift+Enter). Для админки: панель сессии (статус, токены, кто ведёт,
  «перехватить» / «вернуть агенту»), конструктор ответа с кнопками и карточками, шаблоны.
- **Границы:** без новых библиотек; только свои элементы (правило студии — никаких стандартных браузерных).
- **Когда готово:** фронтенд делает без вопросов.

## Отчёт
- **Сделано:** `design/design-spec-chat.md` — спецификация чата в стиле v3. В ней: токены `--ok` и анимации «думает», данные `meta.blocks` (ChatBlock), группы сообщений в ленте, markdown,
  быстрые ответы (одиночный и множественный выбор, «свой вариант»), карточки выбора с меткой «рекомендуем», форма с кодом из СМС по ячейкам и свёрнутым итогом,
  оплата, превью/версия, галерея и свой просмотрщик фото и видео, документы, этап, системные чипы, статусы «печатает/думает/человек», ошибка отправки
  с повтором, пустой чат со стартерами, поле ввода. Админка: панель сессии (кнопки «перехватить» и «вернуть агенту»), конструктор блоков с предпросмотром, шаблоны, новый раздел «Сессии».
  Есть таблицы 375/1440, раздел про светлую и тёмную тему и чек-лист для QA.
- **Ограничение:** сейчас API принимает только `meta.buttons`. Блоки (карточки, форма, оплата, версия), «Стоп», размер файла, токены за сессию и счёт от администратора требуют работы бэкенда (п.19 спеки).
  Без неё фронт может сделать: markdown, быстрые ответы, статусы, файлы, системные сообщения, пустой чат, поле ввода, панель сессии и шаблоны.
- **Команда не привлекалась:** работа — спецификация по готовому стилю v3. Макета в Figma нет: формат задачи — спецификация с JSX.
- **Вопросы к заказчику:** 1) может ли администратор выставлять счёт на свою сумму из чата; 2) тексты 4 стартеров пустого чата (сейчас это черновик, помечен [УТОЧНИТЬ]).
- **Новое — на одобрение:** п.21 спеки (8 пунктов).

## Приёмка
Принято менеджером. Счёт на свою сумму из чата — не сейчас (только тарифы и пакеты). Подсказки пустого чата — типовые тексты, без [УТОЧНИТЬ]. Дополнения п.21 — берём. Бэкенд п.19 — в задаче 11 у техлида.
