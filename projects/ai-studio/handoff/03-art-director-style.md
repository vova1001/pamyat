# 03 · art-director · больше стиля + тёмный и светлый фон

## Задача
- **Цель:** заказчик посмотрел v1: «нужен тёмный и светлый фон, немного деталей всяких, чтобы хоть какой-то стиль был».
  Сохраняем минимализм, но добавляем характер.
- **Входные файлы:** `../design/design-spec.md` (v1, свёрстан в ветке `redesign` `/home/user/ai-studio`), скриншоты v1:
  `/tmp/claude-0/-home-user/05a85968-a374-5b44-8ddd-10e073dfbc7c/scratchpad/rd-home-d.png`, `rd-home-m.png`, `rdc-cabinet-d.png`.
- **Что сдать:** `../design/design-spec-v2.md` — только отличия от v1:
  1. **Чередование фонов на главной:** часть разделов тёмные (например, первый экран или «Как это работает» и подвал),
     часть светлые; токены для тёмного раздела (класс-обёртка, которая инвертирует цвета).
  2. **Переключатель темы** (светлая/тёмная/как в системе) в шапке главной и кабинета; тема хранится в localStorage,
     без мигания при загрузке; токены тёмной темы уже есть — уточнить.
  3. **3–5 деталей стиля** без перебора, например: тонкая сетка/точки на фоне первого экрана, акцентный градиент-свечение,
     пример «окна чата» с сообщениями в первом экране как иллюстрация продукта (на CSS, без картинок), бегущая строка
     или моно-метки, мягкое появление блоков. Всё на CSS, без новых библиотек, уважать prefers-reduced-motion.
  Конкретные классы/CSS, чтобы фронтенд сделал без вопросов.
- **Границы:** тексты, тарифы, логику не менять (в иллюстрации чата можно короткие примерные реплики — пометить);
  без 3D, видео, тяжёлых анимаций.
- **Когда готово:** 375/768/1440; обе темы; контраст AA.
