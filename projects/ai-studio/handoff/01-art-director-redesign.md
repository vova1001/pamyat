# 01 · art-director · дизайн редизайна

## Задача
- **Цель:** минималистичный стильный дизайн сайта «Студия ИИ» без перебора (см. `../brief.md`).
- **Входные файлы:** `../brief.md`; код `/home/user/ai-studio/web/src` (стили: `app/globals.css`, `components/ui.ts`;
  главная `app/page.tsx`; вход `app/login/`; кабинет `app/cabinet/`); скриншоты живого сайта:
  `/tmp/claude-0/-home-user/05a85968-a374-5b44-8ddd-10e073dfbc7c/scratchpad/ais-d.png`, `ais-m.png`, `ais-login.png`.
  Память дизайна: `prod/crew/design/`, `prod/components/`, `prod/common/standards.md`.
- **Что сдать:** `../design/design-spec.md` — палитра (светлая и тёмная тема, токены для `globals.css`), шрифты
  (Google Fonts через `next/font`, кириллица), сетка и отступы, кнопки/поля/карточки (классы для `ui.ts`),
  схема главной по блокам (что меняется визуально, тексты те же), вход, шапка кабинета и чат.
  Конкретно — так, чтобы фронтенд сделал без вопросов. Figma не нужна (заказчик ждёт результат на сайте).
- **Границы:** тексты, тарифы, логику не трогать; код не писать; без тяжёлых анимаций, 3D, видео; одна-две
  тонкие детали «стиля», не больше.
- **Когда готово:** спецификация на одну страницу-две, мобильный первым (375), 768, 1440.

## Отчёт
- **Сделано:** `../design/design-spec.md` — направление «тихий редактор»: тёплый светлый фон, почти чёрный текст, один синий акцент, тонкие линии вместо теней.
  В спецификации: токены для обеих тем (`globals.css` целиком), шрифты Onest + JetBrains Mono (next/font, кириллица), сетка и отступы, объект `ui` для `ui.ts`
  с состояниями, разбор главной по блокам, вход, шапка кабинета, чат (пузыри и поле ввода), таблица 375/768/1440, спорные места.
  Дизайнеров не привлекал: задача на 10 минут, без Figma, один исполнитель быстрее. Правило памяти «первый вариант на максимуме» не применял:
  заказчик прямо просил минимализм без перебора, а в границах — одна-две детали.
- **Отступления от памяти:** Figma-макета и эскиза нет (по задаче); `style.md` не делал, направление описано в шапке спецификации.
- **Новое — на ваше одобрение:** 1) главная кнопка чёрная вместо синей; 2) моно-номера разделов и шагов («01», «02»); 3) шаги без карточек, разделены линиями;
  4) квадрат-акцент перед названием в логотипе; 5) липкая шапка на главной с размытием фона; 6) подчёркивание активного пункта в кабинете (нужен маленький клиентский `NavLink`).
- **Вопросы к заказчику:** нравится ли чёрная главная кнопка или нужна цветная; нужен ли переключатель тёмной темы (сейчас — по системе).
- **Нужно дальше:** после вёрстки qa снимает скриншоты 375/768/1440 главной, входа и кабинета для показа; ui-designer сверяет вёрстку со спецификацией.

## Приёмка
Принято менеджером: спецификация полная, минимализм соблюдён. Дополнения 1–6 принимаем (один вариант, без перебора). Тёмная тема — по системе, без переключателя. Чёрная кнопка — показываем заказчику на превью.
