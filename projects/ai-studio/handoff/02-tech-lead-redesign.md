## Отчёт
**Сделано** (коммит `d2e2a51` в ветке `redesign`, не запушен):
- `globals.css` (токены из спецификации), `layout.tsx` (Onest и JetBrains Mono с кириллицей, Inter убран), объект `ui` в `ui.ts`.
- Главная: шапка, первый экран, 01 «Как это работает», 02 «Тарифы», преимущества, подвал. Вход: логотип, карточка, поле кода моно-шрифтом, notice на `brand-soft`.
- Кабинет: шапка, новый `components/nav-link.tsx` (активный пункт подчёркнут), лента и поле ввода в виде капсулы, пузыри (`message-bubble.tsx`), оплата, файлы, профиль, список тарифов.
- `text-red-600` и `bg-red-*` заменены на `danger` во всём коде. В админке: знак логотипа, фильтр чатов `bg-foreground text-background`, остальное подхватилось через `ui`.
- В Tailwind v4 итоговый класс не зависит от порядка классов в строке. Поэтому классы, которые перекрывают базовые из `ui` (`h-12`, `p-0`, `text-2xl`, `text-base` и т.п.), записаны с `!` (например `h-12!`). Иначе, например, поле кода в админке 2FA потеряло бы крупный шрифт. Две карточки (тарифы на главной, вход) свёрстаны без `ui.card`, по классам спецификации.

**Проверено:** `npm run lint`, `npm run typecheck`, `npm run build` проходят без ошибок. В Chromium (Playwright) с настоящим API на 375/768/1440 открыты главная, вход, кабинет, оплата, файлы, профиль. Горизонтальной прокрутки нет, ошибок в консоли нет. Вход прошёл по коду из лога. Подписка оформлена через dev checkout, после неё открылся чат. Скриншоты просмотрены.
