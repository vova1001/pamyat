# 02. analyst: ТЗ

## Задача (пишет менеджер)
- Цель: техническое задание лендинга винодельни с заказом на сайте и кабинетом заказчицы.
- Входные: `projects/wine-landing/brief.md` (раздел Д — данные), `projects/wine-landing/structure.md` (согласованная структура блоков),
  `projects/wine-landing/plan.md`, `prod/niches/wine.md`.
- Сдать: `projects/wine-landing/tz.md` по шаблону из памяти аналитика.
- Границы: блоки сайта берём из согласованной `structure.md`, не придумываем новые; факты — только из брифа.
- Готово, когда: у каждой функции есть сценарий и критерии приёмки; данные описаны (что, сколько, срок);
  есть раздел «Развитие»; вопросы к заказчице собраны.
- Что важно из разговора с заказчицей:
  - языки: русский и английский (переключатель);
  - заказ на сайте: имя, фамилия, почта, Telegram; до 10 заказов в день; хранить всегда;
  - кабинет заказчицы с входом по паролю: видит заказы и данные покупателей;
  - карточки вин (название, описание, цена, фото) заказчица создаёт и меняет сама в кабинете — сразу появляются на сайте;
  - описания пишет на русском, английский перевод — автоматически, с возможностью поправить;
  - продажа вина в Испании (Мадрид), окно 18+;
  - корзина: несколько вин с количеством; оплата онлайн на сайте картой; о новом заказе — сообщение в Telegram заказчице;
  - план продюсера: `projects/wine-landing/plan.md` (модули, принятые дополнения: новые экраны формы заказа,
    переключателя языка и кабинета; удаление данных покупателя по запросу; срок хранения — проверка юриста).
