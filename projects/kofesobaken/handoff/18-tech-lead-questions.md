# 18 · tech-lead · вопросы гостей: форма на сайте + Telegram-бот + ответы

## Задача (пишет менеджер)
- Цель (заказчица): «нужен тг-бот, которому можно писать вопросы, а я их вижу; и форма на сайте — всплывает, пишут вопрос,
  отправляют нам, и чтобы реально приходили ответы».
- Сайт: плавающая кнопка «Задать вопрос» (по стилю сайта, на телефоне не перекрывает нижнюю панель) → всплывающая форма:
  имя, как ответить (почта или Telegram-ник), вопрос, согласие со ссылкой на /privacy; ограничение частоты; спасибо-экран.
- Кабинет: раздел «Вопросы» (новые сверху, отметка «отвечено»), поле ответа.
- Ответ гостю:
  - вопрос с почтой → письмо владелице приходит с Reply-To = почта гостя (отвечает прямо из своей почты — работает без своего
    домена); ответ из кабинета — письмом гостю, только если у Resend подтверждён домен (`MAIL_DOMAIN_VERIFIED=true`),
    иначе в кабинете кнопка «Ответить письмом» = mailto: с подставленной темой и текстом;
  - вопрос через Telegram-бота → гость пишет боту (тот же бот, что для уведомлений), сообщение приходит владелице в её чат
    и в кабинет; владелица отвечает **реплаем** в Telegram или в кабинете → бот отправляет ответ гостю. getUpdates в фоне
    (сайт не засыпает), один обработчик для подключения владелицы и вопросов гостей.
- Без ключей (RESEND_API_KEY, TELEGRAM_BOT_TOKEN) — всё сохраняется в кабинет, ничего не падает.
- Сдать: коммиты в ветку проекта (не пушить), тесты зелёные, `deploy/render.md` обновить.

## Отчёт (пишет исполнитель)
- Сделано:
  - Сайт: плавающая кнопка «Задать вопрос» (телефон — круглая, над нижней панелью; компьютер — с подписью) → окно
    в стиле окна записи: имя, «Почта / Telegram», вопрос, согласие со ссылкой на /privacy, спасибо-экран с адресом
    ответа. 5 вопросов в час с адреса + скрытое поле-ловушка для ботов. Есть бот — в форме ссылка «Напишите нашему боту».
  - Кабинет → «Вопросы» (админ и сотрудники): новые сверху, «ждут ответа / отвечено», счётчик в меню, поле ответа.
    Кнопка по типу вопроса: из бота — «Отправить в Telegram»; почта — «Ответить письмом» (mailto: с темой, текстом и
    цитатой вопроса), с `MAIL_DOMAIN_VERIFIED=true` — «Отправить письмом» с сайта; ник из формы — «Написать в Telegram»
    (открывает чат, ответ копируется). «Отвечено» — отметка без отправки.
  - Владелице: письмо с Reply-To = почта гостя; сообщение в Telegram с подсказкой, как ответить.
  - Бот: фоновый длинный опрос getUpdates (`RunTelegram`), один обработчик на подключение владелицы, вопросы гостей
    и реплаи. Реплай владелицы → ответ гостю реплаем на его сообщение, владелице «Отправлено гостю»; реплай на вопрос с
    почтой — письмом при подтверждённом домене, иначе подсказка. Без дублей при повторной выдаче, offset в базе.
    Гостю: приветствие на /start, «Спасибо, ответ придёт сюда» (не чаще раза в 30 минут), просьба писать текстом на стикеры.
  - Без RESEND_API_KEY / TELEGRAM_BOT_TOKEN всё сохраняется в кабинет, ошибки отправки — понятным текстом, не падает.
  - Вопросы хранятся 1 год (общая очистка); в /privacy добавлена строка «Задаёте вопрос…».
