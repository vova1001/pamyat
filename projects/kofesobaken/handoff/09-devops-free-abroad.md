  база не должна удаляться через месяц; доступность из России (не заблокирован).

  проверено сегодня по официальным страницам.

## Отчёт (пишет исполнитель)
- Сделано: раздел «Бесплатно за рубежом» в `infra/resources.md` (проверено 2026-10-17 по официальным страницам; ничего не регистрировал).
- Итог: зарубежного бесплатного варианта под все 4 условия нет. Наименее плохая связка без карты — Render (сайт, Docker) + Neon (база, бессрочно, 1 ГБ, данные не удаляются).
- Карта: Render и Neon — не требуется; Koyeb, Northflank, Oracle, Google, AWS — карта обязательна (отпали); Hugging Face Docker — только платно.
- Не выполнено условие «не засыпать»: Render засыпает через 15 мин, просыпается ≈1 мин. Плюс переделки: склеить 3 контейнера в один, фото — в S3 (на Render нет диска). Доступность из России не гарантирована (замедление зарубежных облаков с 06.2025).
- Рекомендация: остаться на Cloud.ru из раздела «Старт» — 2 месяца бесплатно бонусами, российская карта, без засыпания и переделок.
- Вопрос к заказчику: устраивает ли «сайт просыпается минуту» и переделки (≈ работа разработчика) ради бесплатного за рубежом — или берём Cloud.ru с бонусами на 2 месяца?
- Риск одной строкой: за рубежом бесплатно = сайт засыпает, фото теряются без переделок, доступность из России не гарантирована.
