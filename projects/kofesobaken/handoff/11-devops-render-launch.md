  в Render — учётные данные реестра с токеном только на чтение; обновление — deploy hook. Заказчику не нужен GitHub, сборка не тратит
  бесплатные минуты Render, закрытый репозиторий не подключается к чужому аккаунту. `DATABASE_URL` (Neon, `sslmode=require`) — только
  в переменных окружения сервиса Render. Выкладка — после задачи 10 (сборки под Render пока нет: нет `render.yaml`, `deploy/render.md`).
- Файлы: `infra/services.md`, `handoff/11a-services-manager-render-neon.md`.
- Вопросы к заказчику (просьба на 2 действия по каждому сервису, без карты):
  1. Render: открыть https://dashboard.render.com/register → своя почта vovaoleshko05@mail.ru и любой пароль → пройти картинку →
     нажать ссылку в письме от Render. Затем в Account Settings → API Keys → Create API Key и передать ключ формой (в хранилище доступов).
  2. Neon: открыть https://console.neon.tech/signup → поставить галочку «Verify you are human» → почта и пароль → код/ссылка из письма Neon.

  заказчик задаст, нам не нужны.

  может снова упереться в ту же капчу — тогда понадобится ещё раз он.
