# Будущие мысли и планы

Не правила, а то, к чему стоит вернуться. Обсуждается с владельцем, в прод — только после решения.

## Вернуть из `parked/`
- Регистрация заказчика в сервисах, оплата по ссылке/QR, коды подтверждения — роль «менеджер по сервисам».
- Запуск на домене, https, деплой — роль «девопс».
- Серверы и железо заказчика — роль «сисадмин».
- Формы с отправкой через сервер — роль «бэкенд».
- Сопровождение после запуска: правки, напоминания о продлении.

## Архитектура
- **Командный режим Claude Code (agent teams):** агенты пишут друг другу напрямую. Пока экспериментальный
  и не работает в неинтерактивном режиме (Agent SDK), поэтому основа — субагенты и файлы-передачи. Пересмотреть, когда стабилизируется.
- **Встроенная память субагентов** (поле `memory` → `.claude/agent-memory/<агент>/MEMORY.md`, грузится сама):
  удобно, но агент сам себе дописывает память — в проде нам нужна только одобренная. Можно использовать в лаборатории.
- **Модели по ролям:** простые роли (переводчик, SEO, юрист-чеклист) — на более лёгкой модели ради цены.
- **Оценка прод-команды:** набор ~20 тестовых заказчиков и оценщик с рубрикой (факты, полнота, тон, уровень) —
  так советует Anthropic для мультиагентных систем.
