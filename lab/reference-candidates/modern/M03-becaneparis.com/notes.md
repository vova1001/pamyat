# M03 — becaneparis.com

Сайт: https://www.becaneparis.com/

**Приём:** Манифест огромным узким шрифтом + WebGL-искажение фото

**Что видно:** Текст-манифест на весь экран узким капсом, фото искажаются шейдером при наведении/скролле.

**Как сделано:** Three.js (WebGL) шейдер на изображениях, крупная типографика condensed-шрифтом.

**Найдено в коде страницы:** Three.js, WebGL canvas, Next.js, видео

**Кому из наших заказчиков подойдёт:** бренды одежды, мастерские, барбершопы

Файлы: `1-first.jpg`, `2-middle.jpg`, `3-later.jpg`, `flythrough.mp4` (прокрутка вживую, 14 с).
