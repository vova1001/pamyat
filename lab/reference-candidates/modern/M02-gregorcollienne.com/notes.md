# M02 — gregorcollienne.com

Сайт: https://gregorcollienne.com/

**Приём:** Облако фотографий вокруг названия

**Что видно:** Десятки фото разбросаны вокруг имени и двигаются с разной скоростью при прокрутке и движении мыши — эффект глубины.

**Как сделано:** Фото с absolute-позициями, translate по scroll/mousemove с разным коэффициентом для слоёв (параллакс).

**Найдено в коде страницы:** определить по коду не удалось — эффекты на CSS/собственном JS

**Кому из наших заказчиков подойдёт:** салоны, фотографы, рестораны, винодельни (галерея)

Файлы: `1-first.jpg`, `2-middle.jpg`, `3-later.jpg`, `flythrough.mp4` (прокрутка вживую, 14 с).
