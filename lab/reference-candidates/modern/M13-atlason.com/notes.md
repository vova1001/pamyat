# M13 — atlason.com

Сайт: https://atlason.com/

**Приём:** Огромный логотип + переходы между страницами

**Что видно:** Название на весь экран, при переходе страница не мигает, а плавно сменяется.

**Как сделано:** Barba.js + GSAP для переходов, видео, mix-blend-mode.

**Найдено в коде страницы:** видео, mix-blend-mode, GSAP, Barba (переходы)

**Кому из наших заказчиков подойдёт:** мебель, интерьеры, премиум-магазины

Файлы: `1-first.jpg`, `2-middle.jpg`, `3-later.jpg`. Видео: у сайта своя система прокрутки, автоматически прокрутить не удалось — запись показывает только первый экран с логотипом; смотреть вживую по ссылке.
