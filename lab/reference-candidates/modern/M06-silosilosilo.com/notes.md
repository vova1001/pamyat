# M06 — silosilosilo.com

Сайт: https://www.silosilosilo.com/

**Приём:** Продукт меняет материал при прокрутке

**Что видно:** Продукт крупно в реальных фото; при скролле переключаются варианты (алюминий/латунь/титан), руки в кадре.

**Как сделано:** GSAP ScrollTrigger + последовательность фото/видео, Swiper для вариантов.

**Найдено в коде страницы:** GSAP, ScrollTrigger, Lenis (плавный скролл), Swiper, видео, Webflow

**Кому из наших заказчиков подойдёт:** магазины, кондитерские, вино, кофе — продукт в фокусе

Файлы: `1-first.jpg`, `2-middle.jpg`, `3-later.jpg`, `flythrough.mp4` (прокрутка вживую, 14 с).
