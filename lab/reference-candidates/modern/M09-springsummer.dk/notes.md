# M09 — springsummer.dk

Сайт: https://springsummer.dk/

**Приём:** Гигантская типографика на весь экран

**Что видно:** Слова высотой в экран, красный акцент, текст выезжает и бежит строкой.

**Как сделано:** Огромный кегль (vw-единицы), marquee на CSS, Swiper для кейсов.

**Найдено в коде страницы:** Swiper

**Кому из наших заказчиков подойдёт:** студии, бары, смелые бренды

Файлы: `1-first.jpg`, `2-middle.jpg`, `3-later.jpg`, `flythrough.mp4` (прокрутка вживую, 14 с).
