# M04 — oriorai.com

Сайт: https://www.oriorai.com/

**Приём:** Крупный портрет + смена светлых и тёмных экранов

**Что видно:** Лицо крупно на светлом фоне, затем тёмный экран с видео; контрастные переходы между блоками.

**Как сделано:** Видео-вставки, mix-blend-mode для текста поверх фото, смена фона секций по скроллу.

**Найдено в коде страницы:** видео, mix-blend-mode

**Кому из наших заказчиков подойдёт:** косметологи, клиники эстетики, салоны
