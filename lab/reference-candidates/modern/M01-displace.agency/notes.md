# M01 — displace.agency

Сайт: https://displace.agency/

**Приём:** Кинематографичное видео на весь экран

**Что видно:** Видео-герой на тёмной теме, текст поверх, плавная инерционная прокрутка; блоки «стопкой» выезжают по скроллу.

**Как сделано:** Фоновое <video> (WebM+MP4), Lenis для плавного скролла, появление блоков через IntersectionObserver/GSAP.

**Найдено в коде страницы:** Lenis (плавный скролл), видео

**Кому из наших заказчиков подойдёт:** рестораны, бары, винодельни, кофейни

Файлы: `1-first.jpg`, `2-middle.jpg`, `3-later.jpg`, `flythrough.mp4` (прокрутка вживую, 14 с).
