# M14 — apple.com

Сайт: https://www.apple.com/macbook-air/

**Приём:** Эталон продуктового лендинга

**Что видно:** Продукт появляется и поворачивается по скроллу, закреплённые сцены, видео-вставки, огромные заголовки.

**Как сделано:** position: sticky + видео/последовательность кадров по скроллу, крупная типографика.

**Найдено в коде страницы:** видео

**Кому из наших заказчиков подойдёт:** любой продукт: вино, техника, косметика
