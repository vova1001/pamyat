# Черновик памяти

Сюда агент пишет сам, по ходу работы. В прод попадает только через skill `promote`.

## Формат записи

```
### <короткое название>
- Правило: делаем X
- Почему: потому что Y
- Куда: prod/knowledge/<файл>.md (или components/, niches/)
- Источник: владелец | агент
- Подтверждения: <проект-1>, <проект-2>
- Статус: ждёт | в проде (дата) | отклонено
```

Правила записи:
- Без имён, телефонов, адресов клиентов.
- Формулируй как правило для любого проекта, а не историю про один.
- Одинаковое не дублируй — добавляй подтверждение.
