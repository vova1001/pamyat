# Черновики памяти

Сюда агент пишет наблюдения и кандидаты в правила по ходу работы.
В прод попадает только через skill `promote`.

У каждого, кто обучает агента, свой файл — чтобы записи разных людей не конфликтовали:

| Файл | Чей |
|---|---|
| `owner.md` | владелец студии |
| `<имя>.md` | сотрудник (имя латиницей, например `ivan.md`) |

Список сотрудников — `team/members.md`.

## Формат записи

```
### <короткое название>
- Правило: делаем X
- Почему: потому что Y
- Куда: prod/knowledge/<файл>.md (или components/, niches/)
- Источник: владелец | сотрудник (<имя>) | агент
- Подтверждения: <проект-1>, <проект-2>
- Статус: ждёт | ждёт одобрения владельца | в проде (дата) | отклонено
```

## Правила записи
- Без имён, телефонов, адресов клиентов.
- Формулируй как правило для любого проекта, а не историю про один.
- Перед новой записью проверь все файлы в этой папке: похожее уже есть — не дублируй,
  а добавь подтверждение в существующую запись.
