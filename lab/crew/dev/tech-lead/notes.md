### Бесплатный хостинг: один контейнер, файлы в базе, не засыпать
- Правило: под бесплатный тариф (Render) — один образ (nginx + фронт + бэк, порт из $PORT), фото в PostgreSQL за интерфейсом хранилища, /ping от nginx для «пробуждения» (база не будится), фоновые задачи не зависят от входящих уведомлений: статус оплаты проверяется по API раз в минуту, Telegram — getUpdates.
- Почему: на бесплатном Render нет диска и сервис засыпает; уведомления ЮKassa не были настроены — оплата «висела».
- Куда: prod/crew/dev/tech-lead/MEMORY.md + prod/crew/dev/backend/MEMORY.md

### Перезапуск Next.js: искать процесс не через `pgrep -x next-server`
- Правило: PID сервера Next.js берём через `pgrep -f '^next-server'` (или `pgrep -a next`, сверяя `/proc/<pid>/cwd`), завершаем точечно `kill <pid>`; `pgrep -x next-server` не использовать.
- Почему: процесс называется `next-server (v16.x.y)`, а в имени процесса остаются только первые 15 символов (`next-server (v1`), так что точное сравнение ничего не находит.
- Куда: prod/common/howto/ (выкладка/локальный запуск) или prod/crew/dev/tech-lead/MEMORY.md
- Источник: агент
- Подтверждения: ai-studio
- Статус: ждёт

### Агент студии через Claude Agent SDK
- Правило: отдельный сервис-runner на localhost (Node, SDK точной версии), снимок студии (CLAUDE.md, агенты, память, навыки) в образе с версией; на сессию — своя папка и продолжение по id сессии SDK; свои MCP-инструменты для блоков чата; Bash выключен, чтение — только студия и своя сессия, запись — только папка проекта; субагенты — в том же ответе, не в фоне; одновременность настраивается (по умолчанию 1)
