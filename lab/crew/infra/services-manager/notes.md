# Черновик памяти: менеджер по сервисам

Прод-память этой роли — `prod/crew/infra/services-manager/`. Формат записей — `lab/crew/README.md`.

## Записи

### Один пароль или свой на каждый сервис — выбирает заказчик
- Правило: перед первой регистрацией менеджер спрашивает заказчика формой с двумя вариантами: «один пароль, который вы вводите сами, для всех сервисов» или «отдельный надёжный пароль на каждый сервис — создадим сами и выдадим по запросу (безопаснее)». Регистрации — по его выбору.
- Почему: решает заказчик; отдельные пароли безопаснее — утечка одного не открывает остальные, но кому-то удобнее один.
- Куда: prod/crew/infra/services-manager/MEMORY.md + prod/crew/management/manager/communication.md (форма «почта и пароль»)
- Источник: владелец
- Подтверждения: —
- Статус: в проде (2026-10-14)

### Платёжные системы — подключение на заказчика
- Правило: платёжную систему подбирает devops вместе с менеджером (2–3 варианта: комиссия, сроки выплат, нужен ли ИП/ООО, онлайн-касса), заказчик выбирает. Регистрация и настройка кабинета (магазин, ключи API, адрес уведомлений, тестовый режим) — команда. Ключи — только в хранилище доступов. Шаги, которые закон и система требуют от владельца лично (договор, документы, подтверждение личности, подпись, коды банка и Госуслуг), делает сам заказчик — менеджер даёт формой короткую инструкцию до 3 предложений.
- Почему: заказчик ничего не настраивает руками, но юридически значимые действия и банковские коды — только его.
- Куда: prod/crew/infra/services-manager/MEMORY.md, prod/crew/infra/devops/MEMORY.md (варианты), prod/crew/management/manager/communication.md (форма)
- Источник: владелец, формулировка — агент
- Подтверждения: —
- Статус: в проде (2026-10-14)

## Регистрации с капчей — заказчик проходит сам, дальше по API-ключу
- Правило: если на регистрации стоит «я не робот» (hCaptcha, Cloudflare), команда её не проходит: заказчик регистрируется
  сам (2 действия), затем выдаёт ключ API через защищённую форму — дальше всё делает команда по ключу, без входов в аккаунт.
- Причина: тест 02 (Render, Neon) — капча на обеих регистрациях.
- Источник: агент (devops/services-manager), тест 02 КофеСобакен, 2026-10-17.
- Подтверждения: КофеСобакен.
- Статус: ждёт.
