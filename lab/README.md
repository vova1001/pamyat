# Лаборатория

Здесь агента обучают. Устройство — зеркало `prod/` плюс всё, что нужно для обучения.
В сервис не идёт.

| Папка / файл | Что внутри |
|---|---|
| `crew/<отдел>/<роль>/notes.md` | черновики памяти каждой роли — зеркало `prod/crew/` |
| `talk/owner.md` | что агент знает о владельце, его решения |
| `talk/ideas.md` | будущие мысли и планы |
| `talk/mistakes.md` | ошибки агента в работе с владельцем — с полным разбором |
| `talk/questions.md` | открытые вопросы к владельцу |
| `parked/` | история отложенного: сервисы и запуск вернулись в прод 2026-10-14 |
| `talk/proposals/` | предложения владельцу (со статусом) |
| `archive/` | старые черновики (всё из них уже в проде) |
| `rejected.md` | что владелец отклонил — не предлагать снова |
| `changelog.md` | журнал: что и когда ушло в прод |
| `test-clients/` | тестовые заказчики для проверки прод-команды |
| `test-runs/` | прогоны тестов (код не коммитится) |
| `reference-candidates/` | кандидаты в базу референсов — ждут отбора владельца |
