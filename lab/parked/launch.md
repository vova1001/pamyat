# Этап 8. Запуск

Домен и хостинг к этому моменту оформлены и оплачены (этап 7, `11-services.md`).

## Домен
- Предложи 3–5 свободных вариантов: короткие, легко сказать по телефону, без дефисов и цифр.
- Зона: .ru / .рф / .com — по рынку заказчика.
- Регистрация и оплата — по `11-services.md`, только после подтверждения и оплаты заказчиком.

## Хостинг и деплой
- Деплой на хостинг по умолчанию (см. стек в CLAUDE.md).
- Привязать домен, проверить DNS, включить https.
- Редирект с www на без www (или наоборот) — один основной адрес.

## Чек-лист перед сдачей
- [ ] Сайт открывается по домену с https, без ошибок
- [ ] Все кнопки и ссылки работают
- [ ] Тестовая заявка отправлена и дошла
- [ ] Телефон кликабельный на мобильном
- [ ] Проверены ширины 360 / 768 / 1440
- [ ] Нет заглушек: lorem ipsum, `[УТОЧНИТЬ]`, «Ваш текст»
- [ ] title, description, favicon, OG-картинка на месте

- [ ] Карта и адрес верные
