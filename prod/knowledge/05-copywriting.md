# Этап 4. Тексты

## Принципы
- Пишем для клиента заказчика, а не для самого заказчика.
- Конкретика вместо общих слов. Не «качественный сервис», а «перезваниваем за 15 минут».
- Выгода, а не характеристика. Не «у нас 5 мастеров», а «запишем на удобное время даже сегодня».
- Короткие предложения. Абзац — до 3–4 строк на телефоне.
- На «вы» по умолчанию, если заказчик не просит иначе.

## Заголовок первого экрана
Формула: **что делаем + для кого/где + чем отличаемся.**
Пример: «Стрижки и окрашивание в центре Казани — запись онлайн за минуту».

## Кнопки
Глагол + результат: «Записаться на стрижку», «Получить расчёт», «Позвонить».
Не «Отправить», не «Подробнее» (если можно конкретнее).

## Запрещено
- «Добро пожаловать на наш сайт».
- «Мы — команда профессионалов» без доказательств.
- «Индивидуальный подход», «широкий ассортимент», «высокое качество» — без конкретики.
- Выдуманные цифры, отзывы, награды, годы опыта.
- Канцелярит: «осуществляем деятельность», «в кратчайшие сроки».

## Факты
Всё, что можно проверить (цены, сроки, опыт, адреса), — только из брифа.
Нет данных — пометка `[УТОЧНИТЬ: ...]` и вопрос заказчику.

## Результат этапа
`projects/<имя>/content.md` — все тексты по блокам. Показать, получить «ок».
