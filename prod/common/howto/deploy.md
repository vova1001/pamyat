# Выкладка сайта на хостинг

**Когда:** шаг «Запуск» и каждое обновление.

## Вариант А. Свой сервер (VPS) — основной
1. Сервер готовит sysadmin (обновления, вход по ключу, firewall, Docker, резервные копии, мониторинг).
2. Код на сервер: `git clone` закрытого репозитория (ключ развёртывания только на чтение) или готовые образы из
   закрытого реестра.
3. `.env` с секретами из хранилища доступов → `docker compose up -d`; миграции применяются при старте; `/healthz` отвечает.
4. Адрес: DNS на IP сервера, https автоматически (Caddy / certbot), один основной адрес.
5. Обновление — одной командой (скрипт или CI): копия БД → `git pull` / новые образы → `docker compose up -d`.
6. Проверка с телефона и компьютера; устройство сервера — `infra/server.md` (без паролей).

## Вариант Б. Бесплатный старт: Render + Neon (через коннекторы)
1. Код собран в **один образ**: nginx + фронт + бэк, порт из `$PORT`; файлы — в PostgreSQL (диска нет);
   `/ping` отвечает сам nginx.
2. Neon (коннектор): проект в регионе рядом с хостингом → строка подключения **без `-pooler`**, с `?sslmode=require`
   (без `channel_binding`).
3. Render (коннектор): веб-сервис из публичного репозитория кода (`git-repo.md`), runtime docker, путь к Dockerfile,
   план free, регион рядом с базой; переменные окружения — строка базы, почта администратора, ключи сервисов.
4. **Выкладка после push — вручную** (`trigger_deploy`), если у Render нет GitHub-приложения; ждать статус `live`.
5. Первый вход администратора — одноразовая ссылка из логов сервиса (`list_logs`); после настройки пароля переменную,
   выпускающую ссылку при старте, выключить.
6. Сайт не засыпает: пинг `/ping` раз в 10 минут (GitHub Actions по расписанию в публичном репозитории или сам сервер).
   Один сервис 24/7 укладывается в бесплатные 750 часов Render; базу пинг не будит.
7. Переезд на платный тариф или VPS — без переделок: тот же образ / `docker compose`, перенос базы `pg_dump`.

## На чём спотыкаются
- Перезапуск выпускал новую ссылку первого входа — уже отправленная переставала работать.
- Бесплатная база Render удаляется через 30 дней — поэтому база в Neon.
