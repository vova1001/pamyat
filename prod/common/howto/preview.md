# Превью для заказчика до своего адреса

**Когда:** сайт ещё не выложен, а заказчик хочет видеть и пробовать.

## Как устроено
- Статичный эскиз — для первого показа вида. Кабинет в превью — **на живых данных**: общее хранилище превью,
  правка в кабинете сразу видна на сайте, брони и вопросы с сайта — в кабинете; вход по паролю (в хранилище — только
  стойкий хэш).
- Сайт и кабинет — в одном превью (одна ссылка), кабинет открывается кнопкой для заказчика.
- Внешние плитки карт и iframe превью блокирует → карта снимком (`map.md`).
- Как только есть хостинг — показываем настоящий сайт по адресу.
