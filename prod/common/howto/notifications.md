# Уведомления заказчику: почта и Telegram

**Когда:** брони, заказы, записи, вопросы должны приходить заказчику сразу.

## Почта
- Сервис рассылки (Resend) через коннектор: ключ только с правом отправки → переменная хостинга.
- Без подтверждённого домена письма уходят **только на почту владельца аккаунта рассылки** → аккаунт регистрировать
  на почту уведомлений или сразу подтвердить домен сайта. Ответы гостям письмом с сайта — только с доменом.
- Письмо заказчику о вопросе гостя — с Reply-To = почта гостя: «Ответить» в почте сразу пишет гостю.

## Telegram
- Бота создаёт человек у @BotFather (`/newbot` → имя → адрес `<название>_bot` → токен). Токен — в переменные хостинга.
- Сервер читает сообщения сам (getUpdates в фоне, без вебхука — работает и на бесплатном хостинге).
- **Чат заказчика привязывается только одноразовой ссылкой** из кабинета (`t.me/<бот>?start=<код>`, 30–60 минут);
  «Старт» без кода — ответ, как подключить. После привязки — проверочное сообщение.
- Свой аккаунт бот считает заказчиком; проверять гостевые сценарии — со второго аккаунта.

## Что присылать
Новая бронь, заказ, запись, «мест нет», вопрос гостя — с кнопками «Позвонить» (через адрес сайта: Telegram не
открывает `tel:` в кнопках) и «Открыть кабинет». Журнал отправленного — в кабинете.
