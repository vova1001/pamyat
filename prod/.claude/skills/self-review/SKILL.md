# Самопроверка перед показом

Пройди по списку. Найдено — исправь, потом показывай.

## Смысл
- [ ] За 5 секунд на первом экране понятно: что это, для кого, что нажать?
- [ ] Каждый блок из `structure.md` на месте и выполняет свою задачу?
- [ ] Нет выдуманных фактов, отзывов, цифр?
- [ ] Нет заглушек и `[УТОЧНИТЬ]` (или они явно перечислены в сообщении)?

## Вид
- [ ] Скриншоты 375px и 1440px просмотрены.
- [ ] Нет горизонтальной прокрутки, наездов, обрезанного текста.
- [ ] Отступы по шкале, шрифтов ≤ 2, размеры читаемые.
- [ ] Контраст текста достаточный.

## Работа
- [ ] Кнопки и ссылки ведут куда надо, телефон кликабельный.
- [ ] Форма отправляется.
- [ ] Нет ошибок в консоли.

## Память
- [ ] Прочитан `knowledge/mistakes.md` — ни одна из прошлых ошибок не повторена.

После проверки подготовь показ — skill `show-result`.

В сообщении с превью коротко: что сделано, что требует решения, что посмотреть в первую очередь.
