# Новый проект

1. Определи тип задачи: сайт с нуля или доработка готового (см. `knowledge/08-client-communication.md`).
2. Спроси короткое имя проекта латиницей (например `coffee-kazan`). Без имён людей.
3. Создай `projects/<имя>/` с файлами:
   - с нуля: `brief.md` — пустой шаблон по разделам из `knowledge/01-brief.md`;
   - доработка: `audit.md` — по разделам из `knowledge/10-existing-project.md`;
   - `structure.md`, `style.md`, `content.md`, `revisions.md`, `services.md` — пустые.
   - папки `design/approved/` и `assets/`, файл `design/links.md` — пустой.
4. Прочитай `knowledge/00-index.md`, `knowledge/mistakes.md` и файл первого этапа:
   `knowledge/01-brief.md` или `knowledge/10-existing-project.md`.
5. Если в `knowledge/niches/` есть файл этой ниши — прочитай его.
6. Коротко объясни заказчику путь (см. первое сообщение в `knowledge/08-client-communication.md`).
7. Начни бриф с первых 2–3 вопросов или попроси ссылку на текущий сайт.
