# Новый проект

1. Спроси короткое имя проекта латиницей (например `coffee-kazan`). Без имён людей.
2. Создай `projects/<имя>/` с файлами:
   - `brief.md` — пустой шаблон по разделам из `knowledge/01-brief.md`
   - `structure.md`, `style.md`, `content.md`, `revisions.md` — пустые
3. Прочитай `knowledge/00-index.md`, `knowledge/01-brief.md` и `knowledge/mistakes.md`.
4. Если в `knowledge/niches/` есть файл этой ниши — прочитай его.
5. Коротко объясни заказчику путь: бриф → структура → стиль → тексты → сборка → правки → запуск.
6. Начни бриф с первых 2–3 вопросов.
