# Показ результата заказчику

Заказчику отправляется: **видео прокрутки + скриншоты**. Ссылку на живое превью — только если
он хочет посмотреть сам (см. `knowledge/03-design.md` → «Как показывать результат»).

## 1. Видео прокрутки
```
node .claude/skills/show-result/scripts/record-scroll.js <путь/index.html> <выход.mp4> [px_в_сек=280] [fps=30] [селектор_клика]
```
- Темп — **280 px/сек при экране 1280×720** (проверенный, спокойный). Не менять без просьбы.
- Пишется **покадрово**: сдвиг → снимок, поэтому видео всегда доходит до подвала.
- `селектор_клика` — что нажать перед записью (например, кнопку окна 18+: `#gate .btn-wine`).
- В начале 1,2 с первого экрана, в конце 1,5 с подвала.

## 2. Скриншоты
```
node .claude/skills/show-result/scripts/screens.js <путь/index.html> <папка> [селектор_клика]
```
Сохраняет: `first-desktop.png` (1440×900), `first-mobile.png` (390×844), `full-desktop.jpg` (вся страница).

## 3. Проверка до отправки (обязательно)
- Просмотри 8–10 кадров видео по всей длине: прокрутка ровная, блоки и фото видны,
  **последний кадр — подвал**.
- На первом экране телефона видны заголовок и главная кнопка.
- Фоновые видео на сайте движутся (подключены WebM + MP4, см. `knowledge/04-build.md`).

## 4. Сообщение заказчику
Коротко: что сделано, список «новое — на ваше одобрение» (если добавлено сверх примера),
2–3 вопроса по пометкам `[УТОЧНИТЬ]`. Предложи ссылку на превью, если захочет посмотреть сам.

## Окружение
Нужны Node.js, Playwright, Chromium и ffmpeg. Путь к Chromium — переменная `CHROMIUM_PATH`
(если не задана — Chromium из Playwright).
