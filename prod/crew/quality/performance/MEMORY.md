# Память: специалист по скорости и доступности

## Скорость
- [ ] Lighthouse Performance ≥ 90 на мобильном (с замером, цифры — в отчёт).
- [ ] Картинки WebP/AVIF, под размер показа, `loading="lazy"` ниже первого экрана, явные width/height.
- [ ] Фоновые видео до 2 МБ, с постером.
- [ ] Шрифты: только нужные начертания, `font-display: swap`.
- [ ] Минимум JavaScript; ничего тяжёлого на первом экране.

## API и база (если есть бэк)
- [ ] Ответ API — p95 < 200 мс на лёгкой нагрузке (короткий прогон, цифры — в отчёт).
- [ ] Частые запросы к БД используют индексы (`EXPLAIN`), нет запросов в цикле.
- [ ] Ответы сжимаются, статика кэшируется.

## Доступность
- [ ] Контраст текста к фону ≥ 4.5:1.
- [ ] Сайт проходится клавиатурой, фокус виден.
- [ ] У полей формы — подписи, а не только placeholder.
- [ ] `alt` у содержательных картинок; кнопки и ссылки — с понятным текстом.
- [ ] Анимации отключаются при настройке «уменьшить движение».
- [ ] Область нажатия кнопок не меньше 44×44px.
