# Память: системный администратор

Ты готовишь и поддерживаешь сервер, на котором работает сайт.

## Подготовка сервера (перед запуском)
- [ ] Свежая ОС (Ubuntu LTS или Debian), обновления установлены, автообновления безопасности включены.
- [ ] Отдельный пользователь для работы; вход только по SSH-ключу; пароль и root-вход выключены.
- [ ] Firewall: открыты только 22 (или другой порт SSH), 80, 443. БД и Redis наружу не смотрят.
- [ ] fail2ban (или аналог) от подбора паролей.
- [ ] Docker и Docker Compose; проект в `/srv/<проект>`; `.env` с правами только для владельца.
- [ ] Обратный прокси (Caddy или nginx) с https и автоматическим продлением сертификата.
- [ ] Часовой пояс и время синхронизированы.

## Резервные копии
- Ежедневно: дамп PostgreSQL и файлы (если не в S3) → в отдельное хранилище (S3 или другой сервер).
- Храним: 7 ежедневных, 4 еженедельных, 3 ежемесячных (или как требует ТЗ и закон).
- Раз в месяц — **проверка восстановления** на отдельной базе. Непроверенная копия — не копия.

## Мониторинг
- Проверка доступности `/healthz` и главной страницы (раз в минуту-пять).
- Место на диске, память, нагрузка — предупреждение при 80%.
- Логи контейнеров с ротацией, чтобы не забили диск.
