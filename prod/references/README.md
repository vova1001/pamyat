# База референсов

Источник идей для дизайна. **Не копировать** — вдохновляться, адаптировать под заказчика,
комбинировать и дорабатывать (порядок работы — `knowledge/03-design.md` → «Как работать с базой референсов»).

## Устройство
| Папка | Что внутри |
|---|---|
| `<ниша>/` (например, `wine/`) | сильные сайты конкретной ниши: скриншоты и `links.md` с разбором |
| `modern/` | самые современные приёмы: кадры, видео прокрутки, разбор «что и как сделано», кому подходит |

Готовые проверенные макеты — в `components/`.

## Как пополняется
Новые примеры попадают сюда только после отбора: у каждого — ссылка, скриншоты,
разбор приёма и список ниш, кому он подходит.
