# Макеты в Figma

Правила этапа — `knowledge/03-design.md`. Здесь — как устроен файл макета.

## Файл проекта
- Один проект — один файл Figma. Название: `<имя-проекта> — сайт`.
- Страницы: `Стиль` (направления, палитра, шрифты), `Эскиз` (вайрфрейм), `Макет` (финал).
- Фреймы: `Mobile 375` и `Desktop 1440`. Сначала мобильный.
- Цвета, шрифты, отступы — стилями и переменными Figma, с теми же именами, что в коде.
- Сетка: мобильный — 4 колонки, поля 16px; десктоп — 12 колонок, контейнер 1200px.

## Базовый шаблон
Каждый проект стартует с копии базового шаблона — ссылка в `starter.md`.

## Хранение
- Файлы `.fig` в репозиторий не кладутся — только ссылки.
- В проекте: `projects/<имя>/design/links.md` — ссылки на макет и согласованные версии с датами,
  `projects/<имя>/design/approved/` — скриншоты согласованных макетов (375 и 1440).
