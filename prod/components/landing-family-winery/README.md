# Шаблон: лендинг семейного производства (винодельня)

Проверенный макет высокого уровня: видео, анимации, интерактив, мелкие детали оформления.
Превью — в `preview/` (пример заполнения), исходник — `index.html`.

## Когда использовать
- Винодельни, виноградники, сыроварни, фермы, пасеки, маслобойни — семейное производство
  с историей, местом и продуктом.
- Главное действие — заказ (через соцсети, форму или звонок), есть приглашение в гости.
- Для других ниш берём приёмы и уровень, но блоки и расстановку адаптируем под бизнес.

## Фишки
Заставка при загрузке · полноэкранное меню с фото при наведении · появление заголовков
по строкам · плавное появление блоков · «шторка» у фото · параллакс · бегущая строка ·
наведение на карточки · подбор продукта к блюду · горизонтальная лента · закреплённая
кнопка заказа на телефоне · плавающая кнопка чата · окно 18+.

## Что менять под проект
1. **Цвета и шрифты** — переменные в `:root` в начале `<style>`.
2. **Тексты** — все `[…]`; факты только от заказчика.
3. **Фото и видео** — в `assets/`: сначала свои у заказчика; пока их нет — подобранный сток
   с бесплатной лицензией (источники — `assets/sources.md`). Продукт — только реальные фото.
4. **Блоки** — убрать то, чего у заказчика нет (например, «В гости»), и добавить нужные.
5. **Авторы фото** в подвале — оставить для файлов с лицензией CC BY, убрать для своих фото.
6. Показ — видео прокрутки и скриншоты (см. `knowledge/03-design.md`).
