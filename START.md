# Как начать

## Схема
- `prod/` — продукт: агент для клиентов. Только это потом поедет в сервис.
- `lab/` + корневой `CLAUDE.md` + `projects/` — ваша лаборатория. В сервис не идёт.
- Агент сам пишет наблюдения в `lab/inbox.md`, а проверенное автоматически переносит в `prod/`.

## 1. Подготовка
1. Распакуйте папку и откройте её (корень, не `prod/`) в Claude Code.
2. Скопируйте `.env.example` в `.env`.
3. Выполните `git init`, `git add .`, `git commit -m "lab: старт"` — нужно для отката правил.

## 2. Первая проверка «с нуля»
Скажите: **«протестируй прод на клиенте 01»**.
Агент сыграет мастера маникюра без всего и покажет, как прод-агент с ней справился.
Это быстрый способ увидеть, как агент поведёт себя с реальным человеком.

## 3. Реальный проект
Скажите: **«новый проект, я играю заказчика»** — и отвечайте как клиент.
- Не нравится → «так плохо, потому что …» (это правило сразу пойдёт в прод).
- Нужно обсудить → «стоп, режим владельца»; вернуться → «продолжаем».
- Хороший блок → «сохрани как шаблон».

## 4. После проекта
**«сделай разбор»** → агент покажет, что уйдёт в прод. Вычеркните лишнее («не надо 3») или скажите «ок».

## 5. Полезные команды
- «что в inbox?» — посмотреть черновик памяти
- «в прод: <правило>» — сразу отправить правило в прод
- «откати последнее правило» — убрать последнее изменение прода
- «протестируй прод» — проверить прод-агента на тестовых клиентах

## 6. Выгрузка в сервис
Когда база наполнится — в сервис копируется только папка `prod/`.
