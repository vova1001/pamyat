## Репозитории сайтов клиентов
- Организация студии на GitHub: `PamyatS`. Один закрытый репозиторий на клиента, из шаблона `site-template`.
- Приложение Claude для GitHub работает внутри существующих репозиториев, но **создать новый не может**
  (проверено 2026-10-14: 403 «Resource not accessible by integration»). В лаборатории репозиторий
  создаёт владелец вручную, дальше работает агент. В сервисе репозитории должен создавать бэкенд студии
  своим ключом с правом создания репозиториев.

## Ограничения, о которых нужно помнить
- Коннектор Figma умеет и читать, и создавать макеты (create_new_file, use_figma).
  Но у подключённого аккаунта место **View** на тарифе **Starter**: с местом View редактировать
  файлы, скорее всего, нельзя, а на Starter у Figma жёсткий лимит вызовов MCP в месяц.
  Для рабочего режима нужно платное место Full (Professional) — проверить в настройках Figma.
- Регистрация через браузер работает не везде: капча и проверка «вы не робот» могут блокировать
  автоматическую регистрацию. Проверить на выбранном регистраторе и хостинге.
- Коннекторы подключаются в claude.ai → Настройки → Коннекторы и начинают работать
  со следующей сессии.

## Доступ в интернет
- **Лаборатория (облачная среда Claude Code):** сайты вне списка разрешённых блокируются, и агент
  не может сам расширить этот список — это делает только владелец в настройках среды.
  Рекомендация: Network access → **Full**, тогда референсы заказчиков открываются всегда.
- **Сервис (API, Managed Agents):** поиск и чтение сайтов работают на стороне Anthropic и этим
  списком не ограничены. При необходимости можно закрыть отдельные домены в настройках агента.

## 2026-10-18 · выводы теста 02 (КофеСобакен) для сервиса
- **Хранилище доступов (п. 10) — критично.** Без него ключи ЮKassa, Telegram-бота и пароли заказчика шли через чат.
- **Аккаунты студии у хостингов и рассылки** + коннекторы (Render, Neon, Resend подключаются кнопкой) — запуск без
  действий заказчика в чужих панелях.
- **Агенты-руководители должны запускать специалистов** (у техлида и qa-lead в сессии не было инструмента Agent —
  всё делали сами).
- **Превью-стенд студии** (п. «Превью-стенд») — живой сайт с кабинетом до покупки хостинга.
- **Браузерный агент для регистраций** (Claude in Chrome / Computer use на машине студии или в облачном браузере сервиса):
  агент сам регистрирует заказчика (рег.ру, ЮKassa, Search Console, хостинги без коннектора), выбирает тарифы и
  настраивает; данные — из хранилища доступов, коды и капча — от заказчика (форма «код»), оплата — ссылкой. Это
  закрывает все случаи, где в тесте 02 заказчику пришлось заходить самому.
